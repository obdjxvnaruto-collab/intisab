انتساب | INTISAB — حزمة التثبيت كـ PWA

مهم: لا يمكن تثبيت ملف HTML محلي كأنه تطبيق مستقل مباشرةً من Acode. هذه الحزمة جاهزة للنشر على استضافة HTTPS (مثل GitHub Pages)، وبعد فتح الرابط في Chrome تختار: ⋮ ثم إضافة إلى الشاشة الرئيسية / Install app. بعدها يفتح انتساب بواجهة مستقلة دون الحاجة إلى Acode.

الخطوات المختصرة:
1) ارفع كل محتويات هذه الحزمة إلى مستودع GitHub جديد.
2) من Settings > Pages اختر النشر من فرع main والمجلد /(root).
3) بعد ظهور رابط HTTPS افتحه في Chrome على الهاتف.
4) من قائمة ⋮ اختر Install app أو Add to Home screen.

المحاضرات على YouTube تحتاج إنترنت. بيانات التطبيق المحفوظة محلياً تبقى على نفس المتصفح/الجهاز غالباً. هذه الحزمة لا تحوّل الموقع إلى APK أصلي، لكنها تجعل الويب-تطبيق قابلاً للتثبيت ويفتح بواجهة مستقلة.
